# 第二阶段：认识主流币种（BTC、ETH、稳定币）

版本：1.0

资料核对日期：2026-08-29

建议周期：2 周，1 次课前诊断 + 12 个正式课次，共约 12～15 小时

> 本阶段只做知识学习和只读观察，不买币、不连接钱包、不签名、不使用杠杆。课程中的“价值”指网络用途与经济机制，不代表价格判断或投资价值。

## 1. 学习目标

完成后，你应该能够：

1. 区分 Bitcoin 网络与 BTC 资产、Ethereum 网络与 ETH 资产、稳定币协议/发行方与具体 token。
2. 解释 BTC 的 UTXO、工作量证明（PoW）、区块奖励与交易费如何配合。
3. 解释 Ethereum 的账户模型、EVM、智能合约、Gas 和权益证明（PoS）。
4. 说明 ETH 与以太坊上的 ERC-20 token 不是同一类资产。
5. 区分法币储备型、加密资产超额抵押型和算法型稳定币的信任假设。
6. 用统一框架比较 BTC、ETH、USDT/USDC，而不是只比较价格和市值。
7. 识别稳定币的脱锚、发行方、储备、赎回、链与合约、跨链桥、流动性和监管风险。
8. 在区块浏览器中只读定位一笔 BTC 交易和一笔 ETH 交易的关键字段。

## 2. 课前诊断（课次 0，30～45 分钟）

先不查资料回答：

1. BTC、Bitcoin、区块链三者是否同义？
2. ETH 为什么不只是“另一个比特币”？
3. 在以太坊上转 USDC，网络费通常用什么资产支付？为什么？
4. “1 USDT = 1 美元”是协议保证、发行方承诺，还是市场永远成立的事实？
5. 同名 USDT 出现在不同链上时，它们的地址、转账路径和风险是否相同？

把初始答案写进 [`learning-log.md`](learning-log.md)。现在答错没有关系；第 12 课再答一次，用前后差异检验进步。

## 3. 统一分析框架

以后遇到任何加密资产，都先回答下面七类问题：

| 维度 | 要问的问题 |
| --- | --- |
| 目标与用途 | 它解决什么问题？谁需要它？不用 token 能否完成？ |
| 网络与资产 | 它是原生币、链上 token，还是对链外资产的索取权？ |
| 安全与共识 | 谁排序和确认交易？作恶成本是什么？最终性如何形成？ |
| 交易模型 | UTXO 还是账户模型？一笔转账到底改变了什么状态？ |
| 供给与价值流 | 谁能发行/销毁？供应规则是什么？费用付给谁或如何处理？ |
| 信任假设 | 必须信任代码、验证者、矿工、发行方、托管人、预言机或治理中的谁？ |
| 失败方式 | 哪些技术、经济、运营、法律或人为事件会造成损失？ |

每学完一类资产，都做一张七维卡片。这个框架比背“币种排行榜”更耐用。

## 4. 两周课程安排

### 课次 1：BTC 的目标与价值主张（60 分钟）

**详细讲义**：[`lessons/stage-02/lesson-01-btc-purpose.md`](lessons/stage-02/lesson-01-btc-purpose.md)

**核心问题**：没有银行维护总账时，数字价值怎样防止被复制和重复花费？

**必学内容**：

- Bitcoin（网络/协议）与 bitcoin/BTC（原生资产）的区别；
- 点对点电子现金、无许可验证、抗审查与稀缺性分别是什么意思；
- 节点、矿工、钱包、用户的角色边界；
- “数字黄金”是常见叙事，不是协议自动保证的收益结论。

**任务与输出**：

- 阅读比特币白皮书摘要和第 1～4 节（Introduction、Transactions、Timestamp Server、Proof-of-Work）；
- 画一张“用户发起交易 → 节点验证 → 矿工打包 → 更多区块确认”的角色图；
- 用 150 字解释 Bitcoin 为什么需要原生资产 BTC。

**检查问题**：矿工能否随意把无效交易写入并让所有完整节点接受？

### 课次 2：BTC 的 UTXO 与交易（75 分钟）

**详细讲义**：[`lessons/stage-02/lesson-02-btc-utxo-transactions.md`](lessons/stage-02/lesson-02-btc-utxo-transactions.md)

**核心问题**：钱包显示的“余额”在链上实际是什么？

**必学内容**：

- 未花费交易输出（UTXO）、输入、输出、找零；
- 交易 ID、区块高度、确认数、手续费率与总手续费；
- 地址不是账户，钱包也不是装币的容器；钱包管理的是密钥和可花费输出；
- 手续费主要取决于交易数据大小和区块空间需求，不简单等于转账金额的百分比。

**只读练习**：

找一笔已确认的 BTC 交易，在日志中记录：交易 ID、输入数量、输出数量、是否可能有找零、总手续费、所在区块。不要复制或记录任何自己的地址。

**输出**：用纸币找零类比解释 UTXO，并补充这个类比不准确的地方。

### 课次 3：BTC 的 PoW、供给与风险（75 分钟）

**核心问题**：网络怎样决定有效历史，BTC 又怎样进入流通？

**必学内容**：

- 工作量证明、难度调整、累计工作量和最长/最重有效链；
- 区块补贴与交易费的区别；减半是发行节奏变化，不等于价格必涨；
- 供应上限、可分割性与丢失币之间的区别；
- 51% 攻击能做什么、不能做什么；确认数是一种概率风险管理，不是绝对不可逆按钮；
- 主要风险：密钥丢失、托管失败、费用拥堵、软件/治理分歧、监管和市场波动。

**输出**：完成 BTC 七维分析卡，并写出三个“机制事实”和三个“市场叙事”，不能混在一起。

### 课次 4：Ethereum、ETH 与账户模型（60 分钟）

**核心问题**：为什么 Ethereum 被描述为可编程的状态机，而不只是转账网络？

**必学内容**：

- Ethereum 网络、原生资产 ETH 与基于 Ethereum 发行的 token；
- 外部拥有账户（EOA）与合约账户；
- 账户余额/nonce 的状态变化与 BTC UTXO 模型的差异；
- ETH 的用途：支付执行费用、参与网络安全、在应用中作为资产；用途不等于价格保证。

**输出**：做一张 BTC 与 ETH 的“网络、原生资产、交易模型、主要用途”四格对照表。

### 课次 5：EVM、智能合约与 token（75 分钟）

**核心问题**：链上程序能做什么，不能保证什么？

**必学内容**：

- EVM、合约代码、状态与函数调用；
- 部署合约和调用合约都是交易，通常会消耗 Gas；
- ERC-20 是接口标准，不是质量认证；任何符合接口的 token 都可能有完全不同的权限与风险；
- “代码按写下的规则运行”不等于代码无漏洞、预言机正确、管理员无权限或经济模型可靠；
- 交易和合约交互通常不可逆。

**只读练习**：

在 Ethereum 区块浏览器打开一个知名 ERC-20 合约页面，只识别合约地址、token 名称、交易列表和合约标签。不要点击“Connect Wallet”或执行 Write 操作。

**输出**：用 200 字解释“ETH 不是所有以太坊 token 的统称”。

### 课次 6：Gas、费用与二层网络（60～75 分钟）

**核心问题**：为什么同样是转账，不同操作的费用差异很大？

**必学内容**：

- Gas used、Gas limit、基础费用、优先费的概念关系；
- 复杂合约操作通常比简单 ETH 转账消耗更多计算/存储资源；
- 网络拥堵会影响费用，失败交易也可能消耗 Gas；
- 二层网络（L2）用于扩展执行，但引入排序器、跨链桥、提款等待或智能合约等额外假设；
- “便宜的链”不自动等于“同样安全”。

**只读练习**：

找一笔普通 ETH 转账和一笔合约调用，比较状态、From/To、Value、Gas used、交易费和输入数据是否为空。

**输出**：写出 Gas、ETH 与美元计价成本三者的关系，明确哪些变量会变化。

### 课次 7：PoS、ETH 供给与风险（75 分钟）

**核心问题**：Ethereum 如何用质押和惩罚保护共识？

**必学内容**：

- 验证者提议区块、证明（attestation）、最终性和罚没（slashing）的基本作用；
- 质押收益来自承担验证职责，不是无风险利息；
- ETH 同时存在协议发行和费用销毁，净供应会随网络活动变化；不要把 ETH 描述为“固定通胀”或“永远通缩”；
- 主要风险：智能合约、客户端实现、验证者集中、L2/桥、应用权限、MEV、监管与市场波动。

**输出**：完成 ETH 七维分析卡，并写出 PoW 与 PoS 各自要求攻击者付出的资源和可能受到的惩罚。

### 课次 8：稳定币分类与稳定机制（75 分钟）

**核心问题**：稳定币的“稳定”由什么资产、承诺和机制支撑？

**必学内容**：

- 法币储备型：依赖发行方、银行/托管、储备质量、审计/鉴证和赎回渠道；
- 加密资产超额抵押型：依赖抵押率、清算、预言机、智能合约和治理；
- 算法型或弱抵押型：依赖市场激励与信心，压力情景下可能出现死亡螺旋；
- 市场价格接近 1 美元、发行方按 1:1 赎回和所有用户都能直接赎回，是三个不同命题；
- 稳定币降低某一计价单位的短期波动，但没有消除信用、流动性、技术和监管风险。

**输出**：画出三类稳定机制的“支撑来源 → 铸造/赎回 → 失效条件”图。

### 课次 9：USDT 与 USDC 的尽调方法（75～90 分钟）

**核心问题**：阅读发行方网页时，怎样从营销表述走到可核验问题？

**调查清单**：

1. 法律发行主体是谁？持有人拥有什么请求权？
2. 谁能直接铸造和赎回？是否需要 KYC、最低金额、地区资格或费用？
3. 储备包含哪些资产？期限、流动性、托管和集中度怎样？
4. 披露频率如何？是管理层数据、鉴证（attestation）还是完整财务报表审计（audit）？
5. 发行方能否冻结地址、拒绝赎回或更改合约？
6. token 发行在哪些链上？各链的官方合约地址从哪里核对？
7. 压力情景下，赎回渠道和二级市场流动性可能如何失效？

**任务与输出**：

- 分别阅读 Tether 与 Circle 的透明度/储备页面；
- 做一张 USDT/USDC 尽调表，每个结论旁放直接链接和核对日期；
- 至少写出两项“发行方声称”和两项“仍需第三方或监管资料验证”的事项。

不要因为发行方使用“100% backed”或“always redeemable”等措辞，就省略资格、条款、托管和流动性检查。

### 课次 10：脱锚、链与跨链风险（75 分钟）

**核心问题**：同一个稳定币名称为什么可能对应不同风险？

**必学内容**：

- 短暂价格偏离、持续脱锚与不可赎回的区别；
- 原生发行、桥接资产、包装资产和仿冒 token；
- 网络选择错误、合约地址错误、跨链桥故障、交易所暂停充提的后果；
- 流动性枯竭时，屏幕报价不等于可按该价格成交或赎回；
- 黑名单/冻结能力既可能用于合规和失窃响应，也形成中心化控制风险。

**情景练习**：

对“某稳定币跌到 0.97 美元”“交易所暂停该链充值”“同名 token 合约地址不同”三个情景，各写：先核对什么、不要做什么、最坏结果是什么。

### 课次 11：横向比较与情景题（75 分钟）

把前三张七维卡合并成下表，不允许填“价格高/低”或“以后会涨”：

| --- | --- | --- | --- |
| 首要目标 | 待学习者填写 | 待学习者填写 | 待学习者填写 |
| 资产类型 |  |  |  |
| 共识/安全来源 |  |  |  |
| 交易模型 |  |  |  |
| 发行与供应 |  |  |  |
| 费用支付 |  |  |  |
| 必须信任的对象 |  |  |  |

**情景题**：

- 需要长期验证一个无需发行方承诺的稀缺数字资产，首先会研究哪些机制？
- 需要运行链上程序，为什么仅持有应用 token 仍可能需要 ETH？
- 需要短期美元计价媒介，为什么仍要调查发行方、链和赎回路径？

情景题不是让你选择买什么，而是练习把用途映射到技术与信任假设。

### 课次 12：结业任务与测验（90 分钟）

**必做输出**：

1. 一页 BTC/ETH/稳定币比较表；
2. 一份 BTC 只读交易拆解；
3. 一份 ETH 只读交易拆解（含 Gas）；
4. 一份 USDT/USDC 发行方尽调表；
5. 一页“我不会因为稳定而忽略的风险”清单；
6. 重新回答课前诊断，并标出答案改变的原因和来源。

**闭卷测验**：

1. 为什么 BTC 钱包余额可以理解为若干 UTXO 的总和？
2. BTC 交易为什么经常出现找零输出？
3. 矿工与完整节点在交易有效性上分别做什么？
4. ETH 与 ERC-20 token 的关系是什么？
5. 调用失败的 Ethereum 合约为什么仍可能付费？
6. PoS 的质押与罚没怎样提高作恶成本？
7. 为什么不能简单断言 ETH 永远通缩？
8. 法币储备型稳定币至少引入了哪四类中心化信任？
9. “发行方 1:1 赎回”和“任何人在交易所都能以 1 美元卖出”为什么不同？
10. 收到一个稳定币合约地址时，怎样判断它属于正确的币种和网络？

每题 0～2 分：0 = 错误/空白，1 = 要点不完整，2 = 能解释机制和风险。总分至少 16/20，且第 8～10 题不能为 0。

## 5. 常见误区清单

- “BTC 就是区块链”——BTC 是特定网络的原生资产，区块链是更一般的记录结构/系统组成。
- “钱包里存着币”——钱包主要管理密钥并读取链上状态。
- “确认一次就绝对不可逆”——不同网络的最终性机制不同，应理解概率确认或经济最终性。
- “ETH 是比特币的更快版本”——两者的目标、状态模型、可编程性与安全经济学不同。
- “ERC-20 代表官方认证”——它主要是接口标准。
- “Gas 越高说明转的钱越多”——费用与资源消耗和网络需求相关。
- “质押收益等同银行利息”——验证职责、罚没、流动性和资产价格都带来风险。
- “稳定币就是数字美元存款”——法律权利、储备、赎回资格和保障机制可能完全不同。
- “同名 token 一定相同”——必须同时核对网络、官方合约地址和发行路径。
- “储备鉴证就是完整审计”——范围、频率和保证程度需要分别阅读。

## 6. 结业验收

只有同时满足以下条件，才把阶段 2 标记为完成：

- [ ] 课前诊断和 12 个正式课次的日志均有自己的解释和至少一个证据链接；
- [ ] 五项必做成果全部完成，且不含真实账户隐私；
- [ ] 能在 5 分钟内口头比较 BTC、ETH、稳定币的目标和信任假设；
- [ ] 能独立读出 BTC/ETH 示例交易的关键字段；
- [ ] 测验至少 16/20，稳定币安全题无零分；
- [ ] 能明确说出“不知道”和需要继续核验的动态事实；
- [ ] 本阶段没有进行真实资金操作或钱包签名。

通过后再进入第三阶段“钱包、私钥与防骗”。第三阶段通过之前，不建议开始交易所或自托管实操。

## 7. 核心资料（优先顺序）

### Bitcoin

- [Bitcoin 白皮书](https://bitcoin.org/bitcoin.pdf)：先读摘要、引言、交易、时间戳服务器与工作量证明章节。
- [Bitcoin Developer Guides](https://developer.bitcoin.org/devguide/)：重点读 Block Chain、Transactions、Wallets、Mining。
- [Bitcoin 交易指南](https://developer.bitcoin.org/devguide/transactions.html)：用于 UTXO、输入输出、找零和手续费。

### Ethereum

- [Ethereum Learn](https://ethereum.org/learn/)：总体入口。
- [账户](https://ethereum.org/developers/docs/accounts/)与[交易](https://ethereum.org/developers/docs/transactions/)：理解账户模型。
- [智能合约简介](https://ethereum.org/developers/docs/smart-contracts/)：理解代码、状态与合约交互。
- [Gas 与费用](https://ethereum.org/developers/docs/gas/)：理解资源计量。
- [权益证明](https://ethereum.org/developers/docs/consensus-mechanisms/pos/)：理解验证、质押和罚没。

### 稳定币发行方披露

- [Circle：USDC 透明度与储备](https://www.circle.com/transparency)
- [Circle：USDC 条款](https://www.circle.com/legal/usdc-terms)
- [Tether：透明度与储备](https://tether.to/en/transparency/)
- [Tether：法律条款](https://tether.to/en/legal/)

发行方页面适合确认“发行方如何描述自己的产品”，不应被当作全部风险的独立证明。课程进行到稳定币尽调时，再补充所在地监管机构和独立审计/鉴证材料，并记录当日版本。
