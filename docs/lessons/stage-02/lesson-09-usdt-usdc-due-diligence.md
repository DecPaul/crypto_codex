# 课次 9：USDT 与 USDC 的尽调方法

资料核对日期：2026-08-29

建议用时：75～90 分钟

> 本课训练阅读发行方披露，不作“哪个更值得买”的结论。USDT、USDC 的储备、条款、支持网络和监管状态都会变化，必须在学习当天重新核对。不要注册账户、提交 KYC 材料、铸造或赎回。

## 本课要解决的问题

阅读发行方网页时，怎样从营销表述走到可核验问题？

学完后，你应该能做到：

1. 识别法律发行主体与适用条款；
2. 区分持有 token、成为发行方客户和拥有直接赎回资格；
3. 分析储备的数量、质量、流动性、托管与隔离；
4. 区分管理层声明、储备鉴证与财务报表审计；
5. 核对冻结、暂停、升级和支持网络权限；
6. 从发行方官方页面核对链与合约地址；
7. 产出带日期、直链和证据等级的 USDT/USDC 比较表。

## 一、先建立证据等级

| 等级 | 资料 | 能支持什么 | 不能自动支持什么 |
| --- | --- | --- | --- |
| A | 法律条款、监管文件、协议规范 | 权利、义务、规则和适用范围 | 实际执行永远无偏差 |
| B | 独立审计/鉴证报告 | 报告范围与时点内的结论 | 报告期后状况或范围外事项 |
| C | 发行方透明度页面 | 发行方的当前披露和主张 | 独立验证全部风险 |
| D | 区块链数据 | 某链合约供应、交易和权限线索 | 链外储备真实性和法律权利 |
| E | 交易所/聚合网站 | 局部市场价格与流动性观察 | 官方合约身份或可赎回性 |

写报告时用“发行方声称……”而不是把 C 级资料直接改写成无条件事实。若 B 级报告是鉴证，还要读报告对象、时点、程序和限制。

## 二、七步尽调

### 第 1 步：法律主体与适用范围

问：

- 哪个实体发行并承担赎回义务？
- 条款适用于哪个地区和用户类型？
- token 持有人对发行方或储备有什么法律请求权？
- 发行方破产时，储备是否隔离，持有人处于什么顺位？

不要只记录品牌名。相同品牌可能在不同地区使用不同发行实体和条款。

### 第 2 步：直接赎回资格

问：

- 是否必须注册发行方账户并完成 KYC？
- 个人、企业、地区是否有资格限制？
- 最低赎回额、费用、银行账户和处理时间是什么？
- 发行方能否延迟、暂停或拒绝赎回？

普通用户在交易所卖出 token 通常是二级市场交易，不是向发行方直接赎回。

### 第 3 步：储备的五个角度

1. **数量**：储备公允价值是否覆盖流通负债？
2. **质量**：现金、短期国债、回购、货币基金、贷款、其他资产各占多少？
3. **期限与流动性**：能否在压力下及时变现而不大幅折价？
4. **托管与集中度**：由哪些银行、基金或托管人持有？是否过度集中？
5. **法律隔离**：是否与发行方运营资金分离，是否免受其他债权人追索？

“资产超过负债”只回答数量的一部分，不等于所有资产都能即时用于赎回。

### 第 4 步：鉴证不等于完整财务报表审计

- **鉴证（attestation/assurance）**：会计师针对管理层对特定对象、特定时点的声明执行约定准则并发表结论；
- **财务报表审计（financial statement audit）**：覆盖一套财务报表及相关披露，目标和范围更广；
- **管理层数据**：由发行方自行报告，独立保证程度最低。

必须阅读报告标题和正文，不能因为网页写“auditor”就自行把储备报告叫作“全面审计”。Tether 的 2026 信息文件明确说明其季度储备报告不是财务报表，而是从会计记录提取的选定财务信息；Circle 透明度页称其储备报告按鉴证标准提供月度第三方保证，同时另行说明公司财务报表审计安排。这些范围要分别记录。

### 第 5 步：控制权限

核对发行方或合约是否可以：

- 冻结/列入黑名单；
- 暂停转账、铸造或赎回；
- 增发或销毁；
- 升级合约实现；
- 迁移或停止支持某条链；
- 按法律命令处置地址。

这些能力可能用于合规和失窃响应，也形成中心化控制、误操作和密钥风险。评价应同时写两面。

### 第 6 步：网络与官方合约

同一个品牌在多条链上发行。核对顺序：

1. 从发行方官网进入“支持网络/合约地址”页面；
2. 选择正确主网，不混用测试网；
3. 复制公开合约地址仅用于比对；
4. 再打开对应链浏览器交叉核对名称和标签；
5. 明确它是发行方原生、规范桥接还是第三方包装版本；
6. 记录核对日期，因为支持可能停止或迁移。

搜索引擎、钱包图标或 token symbol 都不能单独证明身份。

### 第 7 步：压力情景

至少问：

- 若大量用户同时赎回，谁先获得现金？
- 若某银行关闭，储备能否转移？
- 若发行方暂停某条链，链上 token 怎样处理？
- 若二级市场跌至 0.97，但自己没有直接赎回资格，退出路径是什么？
- 若桥接版本脱锚，原生 token 是否仍正常？

## 三、截至核对日可确认的发行方表述

下面只示范如何写，不应永久照抄数字。

### USDC

- Circle 透明度页称 USDC 储备由高流动性法币储备支持，并提供每周储备披露和月度第三方鉴证；这是**发行方披露**。
- Circle 条款把直接赎回与 Circle Mint 账户、资格、合规、适用法律和费用条件联系起来；非 Mint 用户不因单纯持币就自动成为 Circle 客户。
- 条款保留对地址进行 blocklisting、在特定事件暂停服务及决定支持链的能力。
- Circle 官方合约地址页面区分主网、测试网，并明确某些 `USDC.e` 是桥接表示而非 Circle 原生发行。

### USDT

- Tether 透明度页称流通 Tether token 由其储备支持，这是**发行方声明**。
- Tether 条款说明储备可包括现金、现金等价物及其他资产，也可能包括贷款应收款等；应以最新储备报告核对构成。
- 直接发行和赎回要求成为经验证客户，并受最低金额、费用和其他条件限制。
- 条款说明发行方可停止支持特定协议；第三方包装或桥接 token 不是 Tether 发行、不能直接向 Tether 赎回。
- Tether 2026 信息文件称储备报告按季度发布，并配有独立第三方报告，同时说明报告不是完整财务报表。

以上结论不能代替最新报告，也不表示两者风险相同或优劣已确定。

## 五、怎样读一份储备报告

按顺序找：

1. 报告日期和覆盖时点，而非网页访问日；
2. 报告涉及哪些发行实体和 token；
3. 管理层声明的计量口径；
4. 会计师采用的准则和保证类型；
5. 储备总额与流通负债的定义；
6. 资产分类、估值方法、期限与关联方项目；
7. 报告限制、估计和后续事件；
8. 是否能与链上供应口径合理勾稽。

“储备在某个时点大于负债”不能独自回答全年资金流、发行方全部负债、极端流动性或法律隔离。

## 六、检查问题

1. 为什么品牌名不足以确定承担赎回义务的法律主体？
2. 普通交易所用户持有 USDC 是否必然能直接向 Circle 赎回？
3. 鉴证和财务报表审计为什么不能混称？
4. 储备足额为什么仍可能发生赎回延迟？
5. 冻结能力为什么既有正面用途又有风险？
6. 为什么官方合约地址也要记录网络和核对日期？
7. 发行方透明度页和监管文件的证据角色有什么不同？

<details>
<summary>完成后展开答案要点</summary>

1. 品牌可由多个地区实体运营，权利取决于具体条款和司法辖区。
2. 不必然；直接赎回受到 Mint 账户、资格、合规和条款限制。
3. 两者对象、范围、时点和保证目标不同，必须按报告原名描述。
4. 储备可能需要变现，银行或市场可能中断，发行方也有运营和合规限制。
5. 可配合法律与失窃响应，但也可能误冻、被滥用或形成单点控制。
6. 多链支持、合约升级和停止支持都会变化，同名地址在不同网络也不等价。
7. 前者主要记录发行方主张；后者提供法律/监管框架或外部披露，仍需核对适用范围。

</details>

## 七、完成标准

- [ ] USDT/USDC 表的每个关键结论有直链和日期；
- [ ] 至少两项明确标为发行方声称；
- [ ] 至少两项明确列为待外部验证；
- [ ] 没有把鉴证写成完整审计；
- [ ] 没有把二级市场卖出写成发行方赎回；
- [ ] 合约地址从发行方官方入口核对；
- [ ] 检查题至少答对 6 题。
